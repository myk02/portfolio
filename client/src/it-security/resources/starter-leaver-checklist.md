# Starter & Leaver Checklist — Template

> **Template** — prepared by Mike Waitindi as a reusable starter, not a record of work done for an employer.

## New starter

- [ ] Account created (email, portal logins) — requested by: ______
- [ ] Access granted per role only (least privilege) — approved by: ______
- [ ] Device issued (serial recorded in asset inventory) — asset tag: ______
- [ ] Required software/licences assigned — licences freed from: ______
- [ ] Security briefing given (phishing, passwords, data handling) — date: ______
- [ ] Old employee's shared files/docs transferred or archived — owner: ______

## Leaver

- [ ] Last working day confirmed: ______
- [ ] All accounts disabled on the day (email, portals, VPN/shared drives) — by: ______
- [ ] Device collected and checked (damage, data wiped or archived) — by: ______
- [ ] Licences reclaimed — date: ______
- [ ] Shared passwords the person knew are changed — date: ______
- [ ] Access register updated — reviewed by: ______

Rule: no account stays active after the leaving date. [ADD REAL FACT: your team's leaver deadline, e.g. same-day]
