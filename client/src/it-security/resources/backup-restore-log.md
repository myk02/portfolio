# Backup & Restore Test Log — Template

> **Template** — prepared by Mike Waitindi as a reusable starter, not a record of work done for an employer. Backups only count if a restore has been tested.

## Quarterly restore-test routine

1. Pick one system each quarter (rotate through all of them).
2. Restore its backup to a **test location**, never over live data.
3. Open the restored data and check it is complete and readable.
4. Record the result below. If the restore fails, raise it the same day.
