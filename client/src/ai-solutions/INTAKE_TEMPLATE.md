# INTAKE TEMPLATE — request an AI workflow

Copy this form for each team request. Score at the end; low scores are deferred
or declined — that is the point.

## 1. Problem (2 sentences max)

What work is slow, error-prone, or unreadable today?

## 2. Users

Who does the work, and who checks it? Name the human approver (required).

## 3. Data sources

- Where does the input live? (paste, feed, CRM, sheets…)
- Is any of it personal data? (emails, phones, IDs)
- Live data or copies? How fresh must it be? ("last fetched" label needed?)

## 4. Risk if wrong

What happens if the output is wrong? (wasted hour / lost money / harm to people)

## 5. Owner + success measure

- Owner: [ADD REAL FACT: team + name]
- Success looks like: (e.g. "review time per proposal under 10 min, zero unquoted exports")
- Review date: (re-check in 4–6 weeks)

## Scoring (1–5 each)

| Axis  | Question                                                                 | Score |
| ----- | ------------------------------------------------------------------------ | ----- |
| Value | Hours saved × people, weekly?                                            | /5    |
| Risk  | Cost of error — can a human check catch it cheaply? (5 = easily checked) | /5    |
| Reuse | Will other teams use the same pattern?                                   | /5    |

- **11–15:** build it (with human review matched to the risk).
- **7–10:** small pilot, one team, time-boxed.
- **Below 7:** defer or decline — say so in writing, suggest the plain-code alternative.
